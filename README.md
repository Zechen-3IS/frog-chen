# 签表幸存者

ATP / WTA 签表幸存者数据站。参与者每天选出一场比赛的胜者——选对继续得分，选错淘汰。本站汇总排名、赛历、各站得分与对战统计，便于查分与复盘。

站点预览：https://zechen-3is.github.io/frog-chen/

---

## 页面说明

### 首页

总览入口：上周 / 本周 / 下周赛况、赛地天气，并跳转到各功能页。支持暗色模式与场地主题（硬地 / 红土 / 草地）。

### 即时排名（ATP / WTA）

单巡「当前还活着」的积分排名。可查看今日主选与备选、当前状态（存活 / 未完赛 / 淘汰等）、本站得分、排名升降，以及点开行后的选人明细。进行中比赛会尽量按签表提前反映胜负；第一盘内退赛或 W/O 时可按规则启用备选。

### 冠军积分排名（ATP / WTA）

单巡年终总决赛资格相关的冠军积分榜（Race），字段与用法和即时排名类似，便于对照资格形势。

### 联合即时 / 联合冠军排名

把同一用户的 ATP 与 WTA 积分加总后的总榜。点击用户可打开积分构成面板：按级别、场地查看计入的赛事，以及轮次与积分失效月份。

### 幸存者赛历

分 ATP / WTA，可按年份、赛事级别筛选。点击某站进入该站得分页。

### 各站得分页

展示该站所有参与者的得分与选人过程，并提供本站趣味统计：

| 指标 | 含义 |
|------|------|
| 冠军 | 达到本站理论满分（如大满贯 2000）；可以无人夺冠 |
| 单日克星 | 单场赢球、送走选了对手的人最多 |
| 累计克星 | 整站各轮送走人数合计最多 |
| 最大爆冷 | 同场两边都有人选，选得少的一方赢了；展示选爆冷的用户及选人比 |

### 生涯统计（ATP / WTA）

球员维度的历史表现：参赛、夺冠 / 夺亚、连胜连败、存活率等，便于看长期走势。

### 杀手榜

按「送走多少人」排序的终结者榜，含赛季榜与历年总榜。

### 交手记录（H2H）

任意两名用户的历史对阵与汇总，分 ATP / WTA。
